# Data pendukung

CSV dalam setiap folder merupakan ekspor tabel ringkasan yang tertanam di dashboard. Kolom Pilihan menunjukkan cakupan slicer. Pilih satu cakupan sebelum menjumlahkan: kategori seperti Semua tahun sudah mencakup periode rinci. Mengedit CSV tidak memperbarui template secara otomatis.

## Sumber dan satuan

**Risiko Proyek New York** — [Riwayat jadwal](https://data.cityofnewyork.us/d/95tx-snak) · [Riwayat anggaran](https://data.cityofnewyork.us/d/qj5n-h5qp) · [Pemetaan jadwal dan anggaran](https://data.cityofnewyork.us/d/fb86-vt7u) — NYC Open Data.

**Penjualan dan Pelanggan** — Chen, D. (2012). [Online Retail II](https://doi.org/10.24432/C5CG6D). UCI Machine Learning Repository. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Data di sini telah dibersihkan dan diringkas.

**Kinerja Keuangan** — Microsoft. [AdventureWorksDW](https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/adventure-works/data-warehouse-install-script). Tabel FactFinance dan dimensi akun, organisasi, departemen, serta skenario.

Grafik penjualan memakai ribu atau juta pound sesuai judul visual. Angka grafik keuangan yang berlabel ribu dibagi 1.000. Tabel KPI menyimpan angka pada satuan penuh; K1 sampai K4 mengikuti urutan kartu dari kiri ke kanan.
